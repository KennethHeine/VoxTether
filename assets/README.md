# Assets

This directory contains application assets.

## icon.ico

The application icon should be placed here as `icon.ico`. 

If no icon is provided, the application will use a generated default icon.

## Creating an Icon

You can create an icon using:
- Any icon editor like GIMP, Photoshop, or online tools
- Python with Pillow: Create a 256x256 PNG and convert to ICO
- Use the default generated icon (blue circle with "V" for VoxTether)
